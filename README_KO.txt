CPU Power Tray
==============

Windows의 최소/최대 프로세서 상태를 트레이 메뉴에서 빠르게 변경하는 .NET 8 WinForms 프로그램입니다.

주요 기능
---------
- 실행 파일 및 트레이에 전기/번개 아이콘 표시
- 각 트레이 메뉴에 기능별 아이콘 표시
- 최대 프로세서 상태: 10%~100%, 5% 단위 선택
- 최소 프로세서 상태: 10%~100%, 5% 단위 선택
- 최대값 메뉴에 99% 빠른 전환값 별도 제공
- 트레이 아이콘 왼쪽 클릭: 최대값 75% ↔ 99% 전환
- AC 전원과 배터리 설정을 동시에 변경
- 현재 AC/배터리 최소·최대값 표시
- 현재 선택된 값에 체크 표시
- 고급 전원 옵션 바로 열기
- 최소값과 최대값의 순서가 뒤바뀌지 않도록 자동 보정

빌드 방법
---------
1. .NET 8 SDK를 설치합니다.
2. 빌드.bat를 실행합니다.
3. 생성 파일:
   bin\Release\net8.0-windows\win-x64\publish\CpuPowerTray.exe

주의
----
- 관리자 권한을 요청하도록 설정되어 있습니다.
- Windows의 활성 전원 계획 설정을 변경합니다.
